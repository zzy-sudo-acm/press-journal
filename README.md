# 外刊日课

把读过的英语外刊粘贴进书桌，整理成自己的文章收藏。每天保存第一篇新文章时，日历自动盖章，并显示连续打卡天数。

- 在「阅读书桌」点「粘贴文章」。标题、来源和原文链接可按需填写。
- 点「链接导入」并粘贴外刊文章地址。八家来源按导入框里的列表识别，公开正文由 Jina Reader 提取后直接收藏。遇到登录、订阅或只显示预览的页面，可切换到粘贴正文。
- 收藏按日期分组，每组标出连续阅读的第几天。漏一天后，下一次打卡从第 1 天开始。
- 点击书桌右侧的日历日期，可定位当天的收藏。在「打卡日历」中可以浏览各年的印章。
- 文章可搜索、阅读、编辑和删除。打卡按首次收藏记录，删除文章后仍可在日历上查看当天的印章。
- 阅读页支持字号、纸张和阅读进度。电脑端可用顶栏按钮收起左侧工具栏。
- 展开文章末尾的「阅读理解」即可做题，答完后提交查看得分和正确答案。收藏或编辑文章时，可为每道单选题填写 2–4 个选项并标明答案。题目会随备份与单篇文章一起传输。
- 手机上阅读时，轻点正文可隐藏或显示顶栏，向上滑也能收起。电脑的阅读页可用「传到手机」复制导入链接或下载单篇文件。
- 文章和打卡记录保存在当前浏览器的 IndexedDB 中。换设备时，在旧设备的「备份与恢复」下载 JSON 备份，再在新设备导入并确认覆盖。导入单篇文件只会添加该篇文章及其打卡记录。

## 本地运行

在项目目录运行 `python -m http.server 8080 --bind 127.0.0.1`，再访问 `http://127.0.0.1:8080/`。项目不需要安装依赖或构建。

## GitHub Pages

在仓库的 **Settings → Pages** 中将发布来源设为 **Deploy from a branch → main → / (root)**。移动端打开页面或回到前台时会检查 Pages 已发布的版本，点击提示后更新。

封面 `assets/desk.webp` 使用 ImageGen 生成。画面是一册摊开的杂志、一杯黑咖啡，以及落在鼠尾草绿桌面上的斜窗光。
